# Central de Onboarding Teachy · Escola Sagrada Família

Página com os roteiros de acesso à Teachy para gestores, professores, famílias e alunos da
Escola Sagrada Família, com os tutoriais em vídeo de cada público.

- `index.html`: página de escolha (equipe ou famílias)
- `equipe/` e `familias/`: as duas páginas
- `_videos/`: tutoriais em vídeo (mp4) e capas; o vídeo só carrega quando a pessoa clica
- `Teachy-Guia-para-estudantes.pdf`: guia para estudantes
